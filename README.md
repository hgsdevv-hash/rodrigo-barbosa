# Rodrigo Barbosa — Neuropsicólogo

Site de uma página para Rodrigo Barbosa Nascimento (CRP 03/25741), neuropsicólogo em Feira de Santana, BA.
Foco: avaliação neuropsicológica de TDAH e autismo em adolescentes e adultos.

- Prévia: https://hgsdevv-hash.github.io/rodrigo-barbosa/ (com `noindex` até aprovar)
- Local: `python -m http.server 5810` (preview "rodrigo")
- HTML, CSS e JS puros, com GSAP + ScrollTrigger (CDN) e fonte Switzer (Fontshare)

## Como foi pensado

Direção "palco fixo": metade da tela fica parada (retrato, citação, mapa de funções, laudo) e a outra metade rola com o texto.
A ideia vem de uma frase dele: "o diagnóstico não cria o problema, ele acende a luz em um quarto escuro".
Parte interativa: em "Você se reconhece?", o visitante marca sinais e as funções que a avaliação investigaria acendem; os sinais marcados vão prontos na mensagem do WhatsApp.
